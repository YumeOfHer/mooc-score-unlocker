# MOOC 测验分数本地解锁 (mooc-score-unlocker)

> 一个用于中国大学 MOOC（icourse163.org）的本地成绩显示解锁脚本。

## 📖 项目简介

在一些 MOOC 课程中，虽然学生已经完成了单元测验，但平台可能因为设置原因（如未到成绩公布时间、教师锁定等），在前端页面上将分数隐藏，显示为“解锁得分情况”。

本项目通过纯前端技术，拦截并重新发起浏览器本地已有的成绩查询请求，提取服务器已经下发到本地但被隐藏的真实分数，并替换页面上的锁定文字，帮助用户快速查看自己的测验得分。

## ✨ 核心特性

- **安全无侵入**：通过拦截浏览器原生请求提取数据，不篡改页面核心业务逻辑。
- **动态参数获取**：自动从当前网页 URL 和网络缓存中提取 `tid`、`targetAid` 及 `csrfKey`，无需手动填写，适配不同测验。
- **一键解锁**：执行后在控制台输出真实分数，并自动将网页上的“解锁得分情况”替换为红色分数。
- **纯前端实现**：不需要向第三方服务器发送您的账号密码，所有操作均在您的浏览器本地完成。

## 🛠️ 使用方法

### 方式一：通过 Tampermonkey 油猴脚本使用（推荐）

1. 在浏览器扩展商店安装 [Tampermonkey](https://www.tampermonkey.net/) 插件。
2. 点击浏览器右上角的 Tampermonkey 图标，选择 **“添加新脚本”**。
3. 将本仓库中的 `mooc-score-unlocker.user.js` 文件内容全部复制并粘贴到编辑器中。
4. 按 `Ctrl + S` (Windows) 或 `Cmd + S` (Mac) 保存脚本。
5. 打开中国大学 MOOC 的测验成绩页面，刷新页面即可自动生效。

### 方式二：在浏览器控制台（Console）中运行

1. 打开中国大学 MOOC 的答题/成绩页面。
2. 按下 `F12` 或 `Ctrl + Shift + I` 打开开发者工具。
3. 切换到 **控制台 (Console)** 标签页。
4. 复制 `mooc-score-unlocker.user.js` 中 `(async function() { ... })();` 这部分核心代码，粘贴到控制台并按回车。
5. 观察控制台输出，如果成功，页面上的“解锁得分情况”会变为真实的红色数字。

## 🔧 技术原理

1. **参数提取**：从网页 URL 的 `hash` 部分（`#` 之后）通过正则表达式提取测验 ID (`tid`) 和答题记录 ID (`targetAid`)。
2. **凭证获取**：通过 `performance.getEntriesByType("resource")` 获取浏览器刚刚发起请求的完整 URL，从中提取当前会话真实的 `csrfKey`。
3. **身份认证**：发起 `fetch` 请求时，设置 `credentials: "include"`，强制浏览器携带当前账号的 `Cookie`，以通过服务器身份校验。
4. **数据展示**：请求成功后，从返回的 JSON 数据中提取 `result.targetAnswerform.finalScore`，并利用 DOM 操作替换 `.j-triggerLockScore` 元素的内容。
